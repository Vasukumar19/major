# PatchForge AI — Component Reuse Matrix

This matrix documents the architectural comparison, inspection, and reuse decisions between PatchForge AI components and mature open-source implementations.

---

## Component Reuse Matrix

| Subsystem / Capability | PatchForge Architecture | Upstream Projects Inspected | Reuse Decision | Rationale & Evidence |
| :--- | :--- | :--- | :--- | :--- |
| **Structural Repository Graph** | `patchforge/repository_intelligence/graph.py`, `indexer.py` | **RepoGraph**, **CPG / ARISE**, **NetworkX** | **ADAPTED & ENHANCED (RepoGraph + NetworkX)** | Adapted RepoGraph's AST entity-relationship schema into a clean, queryable NetworkX MultiDiGraph with bidirectional inverse edges and commit-hash disk caching. Avoids dangerous `exec()` imports in upstream RepoGraph while capturing callers, callees, references, tests, inheritance, and imports. |
| **AST & Multi-Level Parsing** | `patchforge/repository_intelligence/parser.py` | **tree-sitter**, **tree-sitter-languages**, **astroid**, Python `ast` | **REUSED (ast + tree-sitter + astroid)** | Deploys Python standard `ast` with tree-sitter and astroid capabilities for cross-language compatibility, structural line spans, decorator tracking, and exception raise/catch identification. |
| **Control Flow & State Flow** | `patchforge/repository_intelligence/flow.py` | **Moatless Tools** (`codeblocks/`), **Aider** | **ADAPTED (Moatless CodeBlocks principles)** | Hierarchical block-level CFG (`if`, `for`, `while`, `try/except`) plus intra-procedural state-flow tracking. Explicitly isolates loop-carried state and attribute mutations that previously caused semantic regression in `psf__requests-1963`. |
| **Test Graph & Traceback Linking** | `patchforge/repository_intelligence/test_graph.py` | **SWE-bench**, **pytest**, **SWE-Doctor** | **INDEPENDENT + ADAPTED** | Elevates test cases and assertions into first-class graph entities. Correlates execution failure tracebacks directly to implicated symbols, source lines, and assertions. |
| **Context Retrieval & Budgeting** | `patchforge/repository_intelligence/retriever.py` | **Moatless Tools** (`file_context.py`), **Aider** (`repomap.py`) | **ADAPTED (Moatless + Aider)** | Implements strict token-budgeted `RepairContext` assembling primary source, call-graph neighborhood, CFG, state flow, test specs, and git history without prompt overflow. |
| **Behavioral Diagnosis Workspace** | `patchforge/repository_intelligence/diagnosis.py` | **SWE-Doctor**, **Agentless** | **INDEPENDENT IMPLEMENTATION** | Prevents direct leap-to-patch errors by enforcing a mandatory diagnosis phase producing Cause, Invariant, Repair Strategy, and Affected Sites prior to patch synthesis. |
| **Multi-Site Target Modeling** | `patchforge/core/target.py` (`MultiSiteRepairTarget`, `EditSite`) | **Agentless** (multi-location), **Moatless Tools** | **ADAPTED & UPGRADED** | Extends repair targets with ranked graph-derived roles (`PRIMARY`, `SECONDARY`, `RELATED_CALLER`, `RELATED_HELPER`, `PROTOCOL_SITE`, `TEST_DERIVED`) verified against repository source. |
| **Graph-Aware Refinement** | `patchforge/repository_intelligence/refinement.py` | **SWE-Doctor**, **RepoGraph** | **INDEPENDENT IMPLEMENTATION** | Maps test failure tracebacks through graph edges to uncover caller-callee contractual violations and dynamically discover secondary repair sites. |
| **Autonomous Agent Tools** | `patchforge/repository_intelligence/agent_tools.py` | **mini-SWE-agent**, **SWE-agent** | **ADAPTED (mini-SWE-agent lean tool pattern)** | Provides 9 high-value structured query tools (`inspect_symbol`, `inspect_callers`, `inspect_callees`, `inspect_references`, `inspect_tests`, `inspect_control_flow`, `inspect_state_flow`, `inspect_git_history`, `inspect_failure`) avoiding tool bloat. |
| **Frontier Model Interface** | `patchforge/models/provider.py` | **LiteLLM**, **OpenRouter**, **Ollama** | **REUSED & EXTENDED** | Clean `ModelProvider` abstracting Ollama local inference (`qwen2.5-coder:14b`), Google Gemini, OpenRouter, and generic `OpenAICompatibleProvider`. |
| **Structured Repair Memory** | `patchforge/memory/episode.py` | **Graphiti**, **Mem0** | **FOUNDATION ESTABLISHED** | Fine-grained `RepairEpisode` dataset structure recording issue, repo, graph context, diagnosis, causal chain, patch, test evidence, failure, refinement, and result. |
